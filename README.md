# Gaboxx

## Descripción

Es un sitio web dedicado a la comunidad gamer, diseñado para ofrecer información, contenido y recursos relacionados con videojuegos. El proyecto presenta una interfaz moderna e intuitiva que permite a los usuarios explorar distintas secciones vinculadas al mundo del gaming.

## Objetivos del proyecto

- Brindar un espacio atractivo para los aficionados a los videojuegos.
- Presentar contenido organizado y de fácil acceso.
- Aplicar conocimientos de desarrollo web utilizando HTML, CSS y JavaScript.
- Ofrecer una experiencia visual agradable y adaptable a distintos dispositivos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Instrucciones para visualizar el proyecto

### Opción 1: Sitio publicado

Acceder al siguiente enlace:

https://lichaa-201x.github.io/Gaboxx/

### Opción 2: Ejecución local

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en cualquier navegador web moderno.

## Estructura del proyecto

- `index.html`: página principal del sitio.
- `styles/`: archivos de estilos CSS.
- `script/`: archivos JavaScript.
- `pages/`: páginas secundarias del sitio.
- `imgs/`: imágenes y recursos gráficos utilizados.

## Estado del proyecto

Proyecto académico desarrollado como práctica de desarrollo web y publicación mediante GitHub Pages.
